# A/B тест и Retention (Мобильные игры)
[👉 Посмотреть код проекта (Jupyter Notebook)](Retention%20a-b.ipynb)

## Цель проекта
Проанализировать результаты A/B тестирования для оценки эффективности новой механики и рассчитать метрики удержания пользователей (Retention Rate) в компании, разрабатывающей мобильные игры.

## Задачи проекта
- Рассчитать Retention Rate игроков по дням от момента регистрации.
- Оценить результаты A/B теста (сравнить целевые метрики между тестовой и контрольной группами).
- Визуализировать полученные результаты для презентации бизнесу.

## Методология и инструменты
- **Инструменты:** Python, Pandas, SciPy, Matplotlib.
- **Методы:** Когортный анализ, разведочный анализ данных (EDA), статистическое тестирование (t-тест, проверка распределений).

## Источники данных
Внутренние логи мобильного приложения:
- `problem1-reg_data.csv` — данные о времени регистрации пользователей.
- `problem1-auth_data.csv` — данные о времени авторизации (заходах в игру) пользователей.

## Результаты и выводы
- Структура платящей аудитории различается: в контрольной группе много мелких платежей (300–400 руб.) и единичные сверхкрупные, тогда как в тестовой группе сформировано ядро плательщиков со средним чеком около 3000 руб., но без экстремальных покупок.
- Тестовое предложение принесло рост ARPU на 5.3% и рост ARPPU на 13%, однако сократило долю платящих (конверсия упала на 6%).
- Проведено статистическое тестирование (Z-тест, t-тест Уэлча и перестановочный тест). Анализ показал, что конверсия в покупку статистически значимо снизилась в тестовой группе (p < 0.05). Различия ARPU и ARPPU оказались статистически незначимы.
- **Итог A/B теста:** Тестовый набор предложений не доказал своей эффективности. Рекомендовано оставить контрольный набор акций.
- Сформулирован исчерпывающий набор продуктовых метрик (North Star, Целевые, Прокси, Guardrail) для оценки усложненных игровых механик в тематических ивентах.

## Визуализация данных
- Построена когортная тепловая карта (Heatmap) для наглядного представления Retention Rate по дням.
- Графики распределения метрик для контроля и тестовой группы в рамках A/B тестирования.

## Применение результатов
Результаты анализа используются продуктовой командой для принятия решения о целесообразности масштабирования новой механики на всех пользователей игры, а также для понимания паттернов возвращаемости игроков.

## Ограничения и сложности
- Данные имели сильные выбросы в распределении доходов (немногочисленные очень крупные платежи в контрольной группе). Это потребовало применения непараметрических статистических тестов (перестановочный тест, t-тест Уэлча) для корректной оценки значимости изменений метрик ARPU и ARPPU без искажения результатов.
