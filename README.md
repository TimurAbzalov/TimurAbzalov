### Обо мне :

Я Аналитик данных / Продуктовый аналитик с финансовым бэкграундом. 

Перешел в аналитику после 7+ лет работы в операционном блоке ВТБ 🏛️.

Для меня важно, чтобы моя работа помогала бизнесу расти 📈. Поэтому я трансформирую сухие массивы данных в конкретные, измеримые решения. 🎯 Моя цель — находить скрытые закономерности, автоматизировать процессы и давать инсайты для принятия правильных управленческих решений на основе цифр, а не интуиции.

Люблю активный отдых и путешествия.

Открыт для сотрудничества! 🚀
